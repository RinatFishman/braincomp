How it works

A small F# command-line app. Your data lives in one SQLite file on your machine; Claude reads it through a handful of tools.

Sync

brain sync copies accounts, contacts, deals and activities from each CRM into one shared shape. Every record keeps the id of the CRM that owns it.

Remember

brain ingest imports your notes; brain remember saves a quick one. Each is linked to the account it mentions and made searchable.

Ask

Claude writes SQL for anything you can count, searches notes for the why, and answers with the ids of the records it means.

Act

Proposed writes are shown to you first. Approved ones go to the right CRM, are mirrored locally, and land in the audit log.

Built to be trusted with your pipeline

A brain that can change your CRM has to be predictable. These rules are in the code, not in a prompt.

Read-only queries

Claude's SQL runs on a connection SQLite itself opens read-only. One SELECT at a time.

Every write needs a yes

Calls, tasks and stage changes are shown in full: what, on which record, in which CRM. The default answer is no.

Full audit trail

Approved, declined and failed proposals are all recorded. brain audit shows the history.

Keys stay with you

CRM tokens live in your environment. Claude sees query results, never credentials.

Get started in a minute

Try it on demo data first. You need the .NET 10 SDK and, to ask questions, an Anthropic API key.

# build and load demo data
$ dotnet build src/CompanyBrain
$ alias brain="dotnet run --project src/CompanyBrain --"
$ brain demo

# no API key needed for these
$ brain stale 30 100000
$ brain search competitor

# talk to it
$ export ANTHROPIC_API_KEY=sk-ant-...
$ brain chat

# connect your CRMs, then sync
$ cp .env.example .env
$ brain sync
CRMWhat you need
SalesforceInstance URL plus an access token, or a Connected App with the client-credentials flow.
HubSpotA private app token with read/write on companies, contacts, deals and engagements.
AirtableA personal access token and base id. Common field names like Name, Stage, Amount are matched automatically.
